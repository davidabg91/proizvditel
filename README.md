# производител.net

Платформа за българските земеделски производители — регистрация на стопанство,
каталог с продукция, директни продажби, съвместна доставка, чат, форум, блог и
рейтинги. Изградена като модерно full-stack приложение.

## Основни функции

- **Регистрация на стопанство** с УРН и въпросник (култури, сортове, площи, добив)
- **Профили** със снимки (площ, продукция, лого), обобщени данни и брояч на посещения
- **Каталог** с търсене и филтри; страници на продукти със снимки, цени и оферти
- **Кошница** и поръчка директно при производителя
- **Начини на плащане**: банков превод, Revolut, наложен платеж
- **Съвместна доставка**: партньорства между производители (взаимен избор) и
  предложения за обща доставка в кошницата
- **Доставчици**: Econt, Speedy, Pigeon Express, лично предаване
- **Оценки** само от потвърдени купувачи
- **Чат** клиент ↔ производител
- **Форум** и **блог** за общността
- **Панел за времето** по локация на устройството (важни за фермери данни)

## Технологии

- [Next.js 16](https://nextjs.org/) (App Router) + React 19 + TypeScript
- Tailwind CSS v4 (собствена дизайн система)
- Prisma 6 + SQLite (локално; портируемо към PostgreSQL)
- NextAuth (Auth.js) — вход със сесии

## Локално стартиране

```bash
# 1. Инсталиране на зависимостите
npm install

# 2. Настройка на средата
cp .env.example .env
# отворете .env и задайте AUTH_SECRET (вж. коментара във файла)

# 3. Създаване на базата данни
npx prisma migrate dev

# 4. Стартиране
npm run dev
```

Приложението е достъпно на http://localhost:3000

## Структура

- `src/app` — страници и API маршрути (App Router)
- `src/components` — UI компоненти и дизайн система
- `src/lib` — помощни функции, база данни, автентикация
- `prisma` — схема и миграции на базата данни

## Бележки

- Плащанията са извън платформата — платформата не обработва пари. За реални
  онлайн плащания директно към производителите може да се интегрира marketplace
  решение (напр. Stripe Connect или myPOS).
- Качените от потребители файлове и локалната база данни не се проследяват от git.
